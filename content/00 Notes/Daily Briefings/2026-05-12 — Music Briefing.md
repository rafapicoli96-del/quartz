## 🛠️ Techniques & Workflow

**Logic Pro — recursos que valem explorar dado o seu deep dive de ontem:**

- **Step Sequencer para hi-hats de trap** — especialmente útil para programar grooves de trap/funk. Permite ratchets e probabilidades que o piano roll não entrega de forma tão visual.
- **Quick Sampler — Slice Mode** — chopa loops automaticamente nos transientes e mapeia para o teclado. Se você gravar ideias de bateria ou samples, esse modo resolve rápido.
- **Flex Time** — manipulação de timing de áudio sem cortes. Arrasta transientes para o grid. Útil em vocais e guitarras gravadas.
- **Smart Controls** — consolidação de parâmetros críticos de uma track em uma interface única. Complementa o sistema de presets que você começou a montar ontem.
- **Summing Stacks** — Cmd+Shift+D para criar track stack de instrumentos relacionados. Mantém o projeto organizado sem esconder sinal.
