# Backlog de Técnicas — Memory Mastery

Técnicas pra aprender e incorporar ao protocolo. Não precisa aprender tudo de uma vez — pegar uma por vez, dominar, depois pegar a próxima.

---

## Técnicas Fundamentais (começar aqui)

- [ ] **Memory Palace (Método dos Loci)** — a técnica mais poderosa de todas. Usar espaços físicos conhecidos como "âncoras" pra informações. Ver `02 Técnicas/Memory Palace.md`
- [ ] **Chunking** — agrupar informações em blocos menores pra facilitar o recall. Já usando instintivamente — aprender a aplicar de forma intencional
- [ ] **Spaced Repetition** — revisar na curva do esquecimento (Anki é o software padrão). Alta ROI pra tudo que envolve estudo
- [ ] **Active Recall** — nunca reler. Sempre testar. Fechar o livro e tentar reproduzir antes de checar

---

## Técnicas Intermediárias

- [ ] **Major System** — converter números em consoantes, formar palavras e histórias. Essencial pra memorizar números longos
- [ ] **PAO System (Person-Action-Object)** — extensão do Major System. Permite memorizar sequências longas com alta velocidade
- [ ] **Link System** — encadear itens de uma lista em uma história absurda e sequencial
- [ ] **Name-Face Association** — criar âncoras visuais entre um nome e uma característica física. Direto aplicável no social

---

## Técnicas de Agilidade Cognitiva

- [ ] **Dual N-Back** — treino científico de memória de trabalho. Apps: Brain Workshop (PC), Dual N-Back (mobile). 15-20 min/dia, 5x/semana. Alta evidência pra TDAH
- [ ] **Speed Reading + Recall** — aumentar velocidade de leitura sem perder compreensão. Depois testar o que reteve
- [ ] **Mind Mapping** — organizar ideias visualmente em vez de linearmente. Treinar a criar mapas de memória após leitura ou estudo
- [ ] **Lateral Thinking Puzzles** — problemas que exigem raciocínio não-convencional. Boa forma de treinar flexibilidade cognitiva

---

## Técnicas Avançadas (depois)

- [ ] **Dominic System** — alternativa ao PAO, criado por campeão mundial de memória
- [ ] **Ben System** — para memorização de baralhos completos de cartas
- [ ] **Journey Method** — combinação de Memory Palace + Link System para sequências longas
- [ ] **Phonetic Pegs** — lista de 100 "ganchos" sonoros numerados pra ancoragem rápida
