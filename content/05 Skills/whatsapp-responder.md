
# Skill: WhatsApp Responder

**Trigger:** Rafa compartilha um print ou descreve uma conversa do WhatsApp e pede sugestões de resposta.

---

## Como identificar quem escreveu cada mensagem no print

Regras para não confundir de quem é cada mensagem:

- **Mensagens do Rafa:** ficam no **lado direito** da tela, fundo **verde**
- **Mensagens da outra pessoa:** ficam no **lado esquerdo** da tela, fundo **cinza/branco**
- **Exceção — citação/resposta:** quando alguém responde a uma mensagem específica, a mensagem citada aparece dentro de um bloco com fundo verde *mesmo que seja uma fala da outra pessoa*. Isso é só a pré-visualização da mensagem referenciada — **não confundir com mensagem do Rafa**.
- **Regra prática:** em caso de dúvida, olhar sempre o **lado** (direita = Rafa / esquerda = outra pessoa). A cor é secundária — o lado é definitivo.
- Se o print estiver cortado ou ambíguo, indicar qual mensagem foi interpretada como de quem antes de sugerir resposta.

---

## O que fazer

1. **Ler o contexto de comunicação do Rafa:**
   `00 Notes/(C) Meu Estilo de Comunicação.md`

2. **Identificar a pessoa** mencionada ou visível no print.
   - Se tiver perfil em `06 People/[nome].md` → lê o perfil
   - Se não tiver → usa só o nome e o contexto da conversa para inferir o registro

3. **Gerar 2–3 sugestões de resposta** — cada uma com uma variação:
   - Uma mais direta / objetiva
   - Uma mais calorosa / expandida
   - Uma com humor (quando cabe)

4. **Junto com as sugestões, indicar:**
   - Em que registro está cada opção (ex: "tom direto", "mais cordial", "com humor")
   - Se houver algo que Rafa deve saber antes de responder (contexto da conversa, pendências em aberto no perfil da pessoa, etc.)

---

## Regras de Estilo

- Nunca usar linguagem corporativa ou formal demais
- Respeitar o registro correto: cliente INT = inglês caloroso-profissional / cliente BR = semi-informal / amigo = solto / namorada = afetuoso-prático
- Usar as expressões e vocabulário documentados no perfil de comunicação — não inventar novos padrões
- Manter o padrão de mensagens em rajada quando for mais de uma ideia
- Nunca sugerir textão quando mensagens curtas servem
- Emoji: só quando faz sentido no contexto (ver perfil)
